# Дані й геометрія

Щоб не міряти по пікселях: усі числа нижче витягнуті з `vectorPaths` майстра
Chart Plot і переведені у відсотки. Підставите їх у `spline()` — отримаєте
рівно ту криву, що в макеті.

## Полотно

```
Canvas          408 × 200      (360 графік + 12 гап + 36 колонка Y-підписів)
Графік          x 0…360
0 %             y = 190        нижня гридлайна = бейзлайн
Максимум осі    y = 8          верхня гридлайна
Гридлайни       8 · 68.67 · 129.33 · 190
Y-підписи       вирівняні по правому краю 408, центр на лінії (baseline = y + 4)
X-підписи       рядок 360 × 18, space-between, гап space/8 від полотна
Разом           408 × 226
```

Формула: `y = 190 − (value / max) × 182`.

## Криві

| Період | Точок | Max осі | Підписи X | Підпис періоду |
|---|---|---|---|---|
| Week | 7 | 9 % | Mon…Sun | Last 7 days |
| Month | 30 | 12 % | Week 1…5 | This month |
| All time | 24 | 15 % | Feb…Dec | All time |

У Month вісь показує **тижні**, а точок 30 — денні. Тому підпис точки під
пальцем дає конкретний день («14 Jul»): це те, чого немає на осі.

### Демо-крива Empty

Геометрія однакова для всіх періодів — вона позначає місце, а не дані. Точки
вже в системі полотна:

```
(0, 168.16) (90, 155.42) (180, 162.70) (270, 146.32) (360, 139.04)
```

## Формула кривої

Catmull-Rom із **асиметричними плечима**: 1/6 сегмента на кінцях кривої і 1/3 у
середині.

```
Дотична в точці i:
  крайні     m = (y[i±1] − y[i]) / (x[i±1] − x[i])
  внутрішні  m = (y[i+1] − y[i−1]) / (x[i+1] − x[i−1])

Сегмент i → i+1, d = x[i+1] − x[i]:
  a1 = (i == 0)     ? d/6 : d/3
  a2 = (i == n−2)   ? d/6 : d/3
  C  (x[i]   + a1, y[i]   + m[i]   · a1)
     (x[i+1] − a2, y[i+1] − m[i+1] · a2)
     (x[i+1],      y[i+1])
```

Це не «якийсь згладжувач»: рівно ця формула дала шляхи в Figma. Monotone або
cardinal з іншим tension дадуть іншу форму, і макет із кодом розійдуться.

Реалізація — `react-native/chartGeometry.ts`, функція `spline()`.

## Area

Area — та сама крива, замкнена на бейзлайн:

```
<line d> L 360 190 L 0 190 Z
```

Заливка — вертикальний градієнт від **вершини кривої** (не від верху полотна) до
бейзлайну: `bg/brand-subtle → bg/default`, `opacity/40`.

Чому не альфа: bound-колір на стопі градієнта затирає прозорість в 1 — на
токенах «фейд у прозоре» неможливий. Тому другий стоп дорівнює фону екрана, і
фейд читається як зникнення. Наслідок: на іншому фоні (не `bg/default`) під
кривою зʼявиться слабка плашка.

## Глоу

Дубль лінії ПІД нею: той самий градієнт, `border-width/3`, layer blur 16,
`opacity/80`. Area опущена до `opacity/40`, інакше глоу не читається поверх неї.

У RN це `FeGaussianBlur stdDeviation=5`. Якщо на Android фільтр гальмує —
замінити стеками строуків без фільтра:

```
6 px @ 0.10   4 px @ 0.16   3 px @ 0.24   → потім сама лінія 2 px
```

## Поінтер

```
snap        найближча точка: round(x / (360 / (n−1))), клемп 0…n−1
вертикаль   x точки, від y=8 до y=190
точка       r 4.5 + глоу r 9 (opacity/40, blur 6)
піл         на space/8 вище точки, центрований по x
клемп       піл не виходить за 0…408; якщо зверху немає місця — падає під точку
```

Значення у пілі — з одним знаком після коми (`6.0%`). Так readout відрізняється
від округленої hero-цифри й не стрибає по ширині.
