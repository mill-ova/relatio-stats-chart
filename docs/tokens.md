# Токени

У блоці немає жодного захардкоженого кольору, радіуса чи відступу: усе на
змінних DS. Hex нижче — резолвнуті значення **для звірки**, у коді читати з теми.

Перевірено лінтом по 369 вузлах майстрів: непривʼязаних значень нуль.

## Градієнти — колекція `Gradient`

| Токен | Light | Dark | Де |
|---|---|---|---|
| `brand/from` | `#569cf8` | `#569cf8` | hero-цифра, лінія, глоу, точка поінтера |
| `brand/to` | `#5a4fd6` | `#6d69e6` | те саме, другий стоп |

Колекції `Color/Semantic` і `Gradient` резолвляться **незалежно** — мод треба
виставляти на обидві, інакше в темній темі поїде або колір, або градієнт.

## Прозорості — `Opacity`

| Шар | Токен |
|---|---|
| Area під кривою | `opacity/40` |
| Глоу під лінією | `opacity/80` |
| Глоу точки поінтера | `opacity/40` |
| База кістки скелетона | `opacity/40` |
| Tint невибраного сегмента | `opacity/60` |
| Tint піла | `opacity/90` |
| Tint вибраного сегмента | `opacity/95` |

Прозорість завжди на **окремому шарі**, не на корені: інакше вона гасить і текст
(у пілі) або шимер (у кістки).

## Відступи — `Spacing`

Драбина **8 / 16 / 24**. `space/20` виведено з обігу.

| Місце | Токен |
|---|---|
| Між зонами обгортки (верх → перемикач → крокер → графік) | `space/24` |
| Усередині текстового блоку | `space/16` |
| Усередині рядків, гап сегментів, полотно → X-підписи | `space/8` |
| Пари лейбл-значення, гап у пілі | `space/2` · `space/4` |

## Ефекти

**Власних тіней у блоці немає.** Глоу — це дубль лінії з блюром, не `shadow`.
Скло — стиль `Glass/Glass` (у пілі), окремим шаром.

## Борг, який цей блок підсвітив

- `strokeWeight = 1` на сегментах `Button` не привʼязаний до `border-width/1` —
  це майстер Button, не цей блок.
- Кінці кривих у макеті не збігаються: Week завершується на 8 %, Month на 7,1 %,
  All time на 13,6 %. Через це hero-цифра стрибає при перемиканні періоду, хоча
  «зараз» одне. Схоже на борг демо-даних — у продукті рахувати hero з останньої
  точки поточного періоду.
